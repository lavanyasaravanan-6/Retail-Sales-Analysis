# 🛍️ Exploratory Data Analysis on Retail Sales

## 📌 Project Overview

The **Exploratory Data Analysis (EDA) on Retail Sales** project focuses on analyzing retail sales data to identify sales patterns, customer purchasing behavior, and business trends.

This project uses Python libraries to clean, explore, analyze, and visualize retail sales data. The analysis helps understand product performance, sales distribution, revenue trends, and customer behavior.

## 🎯 Objectives

- Analyze retail sales transactions.
- Clean and preprocess the dataset.
- Perform Exploratory Data Analysis (EDA).
- Identify sales trends and patterns.
- Analyze customer purchasing behavior.
- Understand product and category performance.
- Visualize important business insights.
- Provide meaningful conclusions based on the analysis.

## 📊 Dataset Description

The project uses a retail sales dataset containing transaction-level information.

Important features may include:

| Feature | Description |
|---|---|
| Transaction ID | Unique transaction identifier |
| Date | Date of purchase |
| Customer ID | Unique customer identifier |
| Gender | Customer gender |
| Age | Customer age |
| Product Category | Category of purchased product |
| Quantity | Number of products purchased |
| Price per Unit | Price of one product |
| Total Amount | Total transaction amount |

## ⚙️ Project Workflow

### 1. Data Loading
- Import the retail sales dataset using Pandas.
- Display the first few records.
- Understand the dataset dimensions and structure.

### 2. Data Cleaning
- Identify missing values.
- Check and remove duplicate records where appropriate.
- Correct data types.
- Handle inconsistent values.
- Prepare the dataset for analysis.

### 3. Exploratory Data Analysis (EDA)
- Analyze total sales and transactions.
- Study customer age distribution.
- Examine sales by gender.
- Identify popular product categories.
- Analyze quantity and purchase amounts.
- Explore monthly and daily sales trends.

The analysis aims to identify:
